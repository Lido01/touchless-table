# Touchless Tables 🍽️📱

Touchless Tables is a modern, contact-free digital menu system. Diners simply scan a QR code placed on their table to instantly view the restaurant's menu, filter by dietary preferences, and place orders directly from their smartphone browsers.

## 🚀 Key Features

* **Instant QR Access:** Scan-and-go functionality with no app installation required.
* **Dynamic Menu Board:** Real-time updates for pricing, availability, and daily specials.
* **Dietary Filters:** Filter items quickly by allergens, vegan, vegetarian, or gluten-free preferences.
* **Order Placement:** Seamlessly send orders from the table straight to the kitchen.
